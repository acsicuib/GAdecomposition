# Execution Results

This directory contains the experimental results generated by the simulation framework. The results are organized into subdirectories for each main experiment scenario (e.g., `expA_*`, `expB_*`, `expC_*`).

Because many raw data files and intermediate models are generated during execution, only a curated subset of high-level summaries, plots, and final solutions are tracked in Git.

## Experiment Directories (`expX_*`)

Each experiment folder contains the aggregated results, statistical analysis, and topology visualizations gathered across all independent runs of the genetic algorithm. The following files are tracked in version control:

### Visualizations & Plots
* **`clustering_dendrogram.pdf`**: A dendrogram showing the hierarchical clustering process used to decompose the infrastructure graph into smaller, independent submatrices.
* **`infrastructure_graph.pdf` / `infrastructure_graph_detailed.pdf`**: Visual representations of the simulated network infrastructure topology, including edge, fog, and cloud nodes, as well as their connections.
* **`optimization_evolution_traditional.pdf`**: A chart displaying the optimization progress (e.g., fitness evolution or convergence) over the generations for the traditional global genetic algorithm.
* **`statistical_boxplot_speedup.pdf`**: Boxplots comparing the execution time and computational speedup achieved by the Decomposition Genetic Algorithm (DC-GA) versus the traditional global approach.
* **`statistical_boxplots_metrics.pdf`**: Boxplots comparing the final multi-objective metrics (such as Mean Response Time and Total Price) obtained by the different algorithmic approaches across all runs.

### Summaries & Statistical Reports
* **`simulation_summary.md`**: A detailed summary of the experiment's configuration, parameters, hardware settings, and global aggregated results.
* **`submatrices_summary.md`**: A report detailing the characteristics of the generated submatrices, including node groupings, graph partitioning details, and assigned application workloads.
* **`wilcoxon_statistical_report.md`**: A statistical report containing the results of the Wilcoxon signed-rank tests, used to determine the statistical significance of the performance differences between the evaluated algorithms.

---

## Independent Run Directories (`run_N`)

Because genetic algorithms are stochastic, each experiment consists of multiple independent executions (runs) to ensure statistical validity. Inside each experiment directory, there are multiple `run_N` subfolders (e.g., `run_0`, `run_1`, etc.). The following files from these specific runs are tracked:

* **`global_pareto_solutions.txt`**: A text document containing the final set of non-dominated solutions (the Pareto front) discovered in this specific run. It lists the objective values (e.g., Latency, Cost) alongside the exact service placement assignments for each solution.
* **`pareto_evolution_global.pdf`**: A scatter plot illustrating the evolution and convergence of the Pareto front over successive generations for the traditional global approach.
* **`pareto_evolution_submatrix_traditional.pdf`**: A scatter plot illustrating the Pareto front evolution when applying the submatrix-based decomposition approach compared to the traditional baseline in this specific run.
